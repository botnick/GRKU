# GRKU

RICOH GR IV および GR IV HDF ファームウェア 1.11 専用です。

GRKU は試験的なソフトウェアで、保証はありません。GRKU に問題があると、カメラが起動中に止まることがあります。インストール前に[復旧ガイド](https://github.com/botnick/GRKit/blob/main/resources/RECOVERY.md)をお読みください。GRKU をインストールした時点で、[利用規約](https://github.com/botnick/GRKit/blob/main/resources/TERMS.md)に同意したものとみなされます。

## インストール

パソコンの Chrome または Edge で、[grku.app](https://grku.app/) を使うと、カードリーダーに入れたカードに GRKU を書き込むことができます。これは手順 2 の代わりになります。

1. カメラの電源を切ります。
2. `SD_ROOT` フォルダーそのものではなく、その中身を SD カードのルートにコピーします。コピーすると、カードのルートに `SCRIPT` フォルダーがある状態になります。
3. カードを挿入します。MENU を押しながらカメラの電源を入れます。カメラが自動的に電源オフになるまで待ちます。
4. カメラの電源を通常どおり入れます。

手順 3 でカメラの SD スクリプトが有効になります。カメラに Mode Set Command と Complete が表示され、その後自動的に電源が切れます。SD スクリプトがすでに有効になっている場合は、手順 3 を省略してください。

![Mode Set Command 画面には Script - Enable と Complete が表示されます。](images/modeset.png)

インストール後、カードのルートから `00078560.636` と `DEVELOP.MOD` を削除してかまいません。

電源を入れてから数秒後、撮影画面の上部に **GRKU** が表示されます。これは GRKU が読み込まれたことを示しています。インストールまたはアップデート後の最初の起動には、より時間がかかります。GRKU が読み込まれる前に撮影した写真には、GRKU の効果は適用されません。撮影モードで ADJ レバーを押し、6番目の項目である GRKU を選択します。

- **フィルムルック:** 効果をハイライトするとライブビューでプレビューでき、OK を押すとその効果が保持されます。Fn を押すと効果を調整できます。カメラの Image Control 設定は変更されません。これらの効果は GR III 向けに作られているため、GR IV では色が異なる場合があります。
- **フレーミング:** XPan、2.35:1、16:9、その他の比率です。JPEG 写真はトリミングされ、DNG ファイルは 3:2 のままになります。Fn を押すと、構図のためだけにフレームを使用するか、マスクを設定するかを選べます。
- **ガイド:** 画面上の線のみで、写真には写り込みません。
- **日付写し込み:** 写真の右下に日付が表示されます。Fn を押して日付のスタイルとフォントを選択できます。
- **グロー:** ブルームとハレーションで、JPEG 写真のみに適用され、ライブビューでのプレビューはありません。
- **光漏れ:** ビネット、ダスト、光漏れ、傷で、JPEG 写真のみに適用され、ライブビューでのプレビューはありません。Fn を押してそれぞれの強さを設定できます。
- **拡散:** Black Pro-Mist ディフュージョンフィルターのような輝きで、JPEG 写真のみに適用され、ライブビューでのプレビューはありません。Fn を押して、シャドウ部分にベールをかける Black Mist や、アナモルフィックレンズの水平フレアである Streak を追加できます。
- **粒状感:** 写真にフィルムの粒状感を加えます。Fn を押して粒状感のサイズを選択できます。
- **ボーダー:** 写真の上に幅の 3% または 6% の白または黒の縁を追加し、JPEG 写真のみに適用されます。

すべての設定は、MENU のカスタマイズタブ (C) の最後にある **GRKU** セクションにもあります。各モジュールに1行が割り当てられています。そこでモジュールのオン/オフを切り替え、ADJ が **Options** に表示する効果、比率、スタイルを確認し、**ADJ Order** で順序を設定します。GRKU は電源を切った後も設定を保持します。

## アップデート

パソコンの Chrome か Edge で [grku.app](https://grku.app/) を開くと、カードリーダーのカードを直接アップデートできます。手順 2 と 3 の代わりになります。

1. カメラの電源を切ります。
2. カードから `SCRIPT` フォルダーを削除します。
3. 新しいパッケージの `SD_ROOT` にある `SCRIPT` フォルダーを SD カードのルートにコピーします。
4. カメラを通常どおり起動します。MENU を押す必要はありません。

設定とエフェクトは `GRKIT` フォルダーに保存されるので、アップデート後も残ります。GRKit から GRKU へ移行する場合は、設定とエフェクトを引き継ぐため grku.app を使用してください。どちらも同じ `GRKIT` フォルダーに保存します。

## トラブルシューティング

### MENU ボタンを押したまま電源を入れると、ファームウェアの更新が始まる

カードのルートにファームウェアのファイルがあります。カメラの電源を切り、カードのルートから `.bin` ファイルをすべて削除してから、インストールの手順 3 をやり直します。

### Mode Set Command が表示されない

- MENU ボタンを押したまま電源を入れます。
- `SD_ROOT` の中身は、`DCIM` などのフォルダーではなく、カードのルートにコピーします。

### ADJ モードに GRK が表示されない

1. 電源を入れて、撮影画面の上部に **GRKU** が表示されるまで数秒待ちます。
2. カードのルートに `SCRIPT` フォルダーがあることを確認します。
3. カードに `SCRIPT/GRKIT/INSTALL.ERR` がある場合は、カメラのメニューで、対応するファームウェアのバージョンが表示されていることを確認します。対応している場合は、`INSTALL.ERR`、`GRKIT/REPORT.TXT`、`GRKIT/BOOT.TXT`（ある場合）を添えて[デバイスレポート](https://github.com/botnick/GRKit/issues/new?template=device-report.yml)を送ってください。
4. GRKU は Ricoh の公式ファームウェアでのみ動作します。

### カードをフォーマットした後、GRKU が動かない

フォーマットすると、GRKU とその設定が削除されます。フォーマットの前に `GRKIT` フォルダーをパソコンにコピーします。フォーマットの後、`SD_ROOT` の中身をもう一度コピーし、`GRKIT` フォルダーをカードのルートに戻します。

## GRKU の削除

パソコンの Chrome か Edge で [grku.app](https://grku.app/) を開くと、カードリーダーのカードから GRKU を直接削除でき、SD スクリプトもオフにできます。

カメラの電源を切り、カードから `SCRIPT` フォルダーと `GRKIT` フォルダーを削除します。

SD スクリプトの設定はオンのままです。オフにするには：

1. https://grku.app で、お使いのカメラの SD スクリプトをオフにするファイルをダウンロードします。
2. `SD_ROOT` の中身を SD カードのルートにコピーします。
3. カードを入れます。MENU ボタンを押したまま電源を入れ、電源が自動で切れるまで待ちます。
4. カードのルートから `00078560.636` と `DEVELOP.MOD` を削除します。

起動の途中でカメラが止まった場合は、[復旧ガイド](https://github.com/botnick/GRKit/blob/main/resources/RECOVERY.md)を参照してください。
