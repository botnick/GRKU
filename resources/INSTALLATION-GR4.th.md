# GRKU

สำหรับ RICOH GR IV และ GR IV HDF เฟิร์มแวร์ 1.11 เท่านั้น

GRKU ยังอยู่ในขั้นทดลองและไม่มีการรับประกันใดๆ หาก GRKU ทำงานผิดพลาด กล้องอาจค้างระหว่างเปิดเครื่องได้ โปรดอ่าน[คู่มือการกู้คืนระบบ](https://github.com/botnick/GRKU/blob/main/resources/RECOVERY.md)ก่อนทำการติดตั้ง เมื่อคุณติดตั้ง GRKU จะถือว่าคุณยอมรับ[ข้อกำหนดการใช้งาน](https://github.com/botnick/GRKU/blob/main/resources/TERMS.md)

## ติดตั้ง

เมื่อใช้งานผ่าน Chrome หรือ Edge บนคอมพิวเตอร์ [grku.app](https://grku.app/) สามารถเขียน GRKU ลงในการ์ดผ่านตัวอ่านการ์ดได้โดยตรง ซึ่งใช้แทนขั้นตอนที่ 2 ได้

1. ปิดกล้อง
2. คัดลอกไฟล์ทั้งหมดที่อยู่ในโฟลเดอร์ `SD_ROOT` (ไม่ใช่คัดลอกตัวโฟลเดอร์) ไปไว้ที่รูทของการ์ด SD หลังจากนั้นที่รูทของการ์ดจะมีโฟลเดอร์ `SCRIPT`
3. ใส่การ์ดเข้าไปในกล้อง กดปุ่ม MENU ค้างไว้พร้อมกับเปิดกล้อง รอจนกระทั่งกล้องปิดตัวเองลง
4. เปิดกล้องตามปกติ

ขั้นตอนที่ 3 เป็นการเปิดใช้งานสคริปต์บนการ์ด SD ของตัวกล้อง: กล้องจะแสดงข้อความ Mode Set Command และ Complete จากนั้นจะปิดตัวเองลง หากระบบสคริปต์บนการ์ด SD ถูกเปิดใช้งานอยู่แล้ว ให้ข้ามขั้นตอนที่ 3 ได้เลย

![หน้าจอ Mode Set Command แสดงข้อความ Script - Enable และ Complete](images/modeset.png)

หลังจากการติดตั้งเสร็จสิ้น คุณสามารถลบไฟล์ `00078560.636` และ `DEVELOP.MOD` ออกจากรูทของการ์ดได้

## การใช้งาน

สองสามวินาทีหลังจากเปิดเครื่อง หน้าจอถ่ายภาพจะแสดงคำว่า **GRKU** ที่ด้านบน: แสดงว่า GRKU โหลดเสร็จแล้ว การเปิดเครื่องครั้งแรกหลังจากการติดตั้งหรืออัปเดตจะใช้เวลานานกว่าปกติ ภาพถ่ายที่ถ่ายก่อนที่ GRKU จะโหลดเสร็จจะไม่มีเอฟเฟกต์ของ GRKU ในโหมดถ่ายภาพ ให้กดปุ่ม ADJ แล้วเลือกรายการที่หก ซึ่งก็คือ GRKU

- **Film Look:** เลื่อนแถบเลือกไปยังเอฟเฟกต์เพื่อดูตัวอย่างในไลฟ์วิว และกด OK เพื่อใช้งาน กด Fn เพื่อปรับแต่งเอฟเฟกต์ ฟังก์ชันนี้ไม่ได้เปลี่ยนการตั้งค่า Image Control ของกล้อง เอฟเฟกต์เหล่านี้สร้างขึ้นสำหรับ GR III ดังนั้นโทนสีอาจแตกต่างไปเมื่อใช้บน GR IV
- **Framing:** สัดส่วนภาพ XPan, 2.35:1, 16:9 และสัดส่วนอื่นๆ ฟังก์ชันนี้จะครอบตัดภาพ JPEG ส่วนไฟล์ DNG จะยังคงเป็น 3:2 กด Fn เพื่อใช้กรอบสำหรับจัดองค์ประกอบภาพเท่านั้น หรือตั้งค่ามาสก์
- **Guides:** เส้นนำสายตาบนหน้าจอเท่านั้น ไม่ปรากฏในภาพถ่าย
- **Date Imprint:** วันที่ที่มุมขวาล่างของภาพถ่าย กด Fn เพื่อเลือกรูปแบบวันที่และฟอนต์
- **Glow:** Bloom และ Halation ใช้ได้กับภาพ JPEG เท่านั้น และไม่มีการแสดงตัวอย่างในไลฟ์วิว
- **Light Leak:** ขอบมืด ฝุ่น แสงรั่ว และรอยขีดข่วน ใช้ได้กับภาพ JPEG เท่านั้น และไม่มีการแสดงตัวอย่างในไลฟ์วิว กด Fn เพื่อตั้งค่าความเข้มของแต่ละเอฟเฟกต์
- **Diffusion:** แสงฟุ้งแบบฟิลเตอร์ Black Pro-Mist ใช้ได้กับภาพ JPEG เท่านั้น และไม่มีการแสดงตัวอย่างในไลฟ์วิว กด Fn เพื่อเพิ่ม Black Mist ฝ้าฟุ้งเหนือเงามืด หรือ Streak แฟลร์แนวนอนแบบเลนส์อะนามอร์ฟิก
- **Grain:** เกรนฟิล์มบนภาพถ่าย กด Fn เพื่อเลือกขนาดเกรน
- **Border:** ขอบสีขาวหรือสีดำบนภาพถ่าย ขนาด 3% หรือ 6% ของความกว้างภาพ ใช้ได้กับภาพ JPEG เท่านั้น

การตั้งค่าทั้งหมดสามารถเข้าถึงได้จากส่วน **GRKU** ที่ด้านล่างสุดของแท็บ Customize (C) ใน MENU เช่นกัน แต่ละโมดูลจะมีแถวของตัวเอง สามารถเปิดหรือปิดโมดูลได้จากที่นั่น เลือกเอฟเฟกต์ สัดส่วนภาพ หรือรูปแบบที่ต้องการให้ ADJ แสดงได้ใน **Options** และกำหนดลำดับการแสดงผลได้ใน **ADJ Order** โดย GRKU จะยังคงจำการตั้งค่าไว้หลังจากปิดเครื่อง

## การอัปเดต

เมื่อใช้งานบนคอมพิวเตอร์ผ่าน Chrome หรือ Edge เว็บไซต์ [grku.app](https://grku.app/) สามารถอัปเดตการ์ดที่อยู่ในตัวอ่านการ์ดได้โดยตรง ซึ่งจะใช้แทนขั้นตอนที่ 2 และ 3

1. ปิดกล้อง
2. ลบโฟลเดอร์ `SCRIPT` ออกจากการ์ด
3. คัดลอกโฟลเดอร์ `SCRIPT` จาก `SD_ROOT` ของแพ็กเกจใหม่ไปยังตำแหน่ง root ของการ์ด SD
4. เปิดกล้องตามปกติ โดยไม่จำเป็นต้องกดปุ่ม MENU ค้างไว้

GRKU จะเก็บการตั้งค่าและเอฟเฟกต์ต่าง ๆ ของคุณไว้ในโฟลเดอร์ `GRKU` ดังนั้นข้อมูลเหล่านี้จึงยังคงอยู่หลังจากการอัปเดต

## การแก้ไขปัญหา

### กล้องเริ่มการอัปเดตเฟิร์มแวร์เมื่อกด MENU ค้างไว้

รูทของการ์ดมีไฟล์เฟิร์มแวร์อยู่ ปิดกล้อง ลบไฟล์ `.bin` แต่ละไฟล์ออกจากรูทของการ์ด แล้วทำตามขั้นตอนที่ 3 ของการติดตั้งอีกครั้ง

### กล้องไม่แสดง Mode Set Command

- กด MENU ค้างไว้ แล้วเปิดกล้อง
- คัดลอกเนื้อหาใน `SD_ROOT` ไปยังรูทของการ์ด ไม่ใช่ในโฟลเดอร์ `DCIM` หรือโฟลเดอร์อื่น

### GRKU ไม่แสดงใน ADJ

1. รอสักครู่หลังจากเปิดเครื่อง จนกระทั่งหน้าจอถ่ายภาพแสดงคำว่า **GRKU** ที่ด้านบน
2. ตรวจสอบให้แน่ใจว่ารูทของการ์ดมีโฟลเดอร์ `SCRIPT`
3. หากในการ์ดมี `SCRIPT/GRKU/INSTALL.ERR` ให้เปิดเมนูกล้องและตรวจสอบให้แน่ใจว่ากล้องแสดงเวอร์ชันเฟิร์มแวร์ที่รองรับ หากรองรับ ให้ส่ง [device report](https://github.com/botnick/GRKU/issues/new?template=device-report.yml) พร้อมไฟล์ `INSTALL.ERR`, `GRKU/REPORT.TXT` และ `GRKU/BOOT.TXT` หากในการ์ดมีไฟล์ดังกล่าว
4. GRKU ทำงานบนเฟิร์มแวร์ทางการของ Ricoh เท่านั้น

### GRKU หยุดทำงานหลังจากฟอร์แมตการ์ด

การฟอร์แมตจะลบ GRKU และการตั้งค่าต่างๆ ก่อนที่คุณจะฟอร์แมตการ์ด ให้คัดลอกโฟลเดอร์ `GRKU` ไปยังคอมพิวเตอร์ หลังจากฟอร์แมตแล้ว ให้คัดลอกเนื้อหาใน `SD_ROOT` อีกครั้ง จากนั้นคัดลอกโฟลเดอร์ `GRKU` กลับไปยังรูทของการ์ด

## นำ GRKU ออก

เมื่อเปิดผ่าน Chrome หรือ Edge บนคอมพิวเตอร์ [grku.app](https://grku.app/) สามารถนำ GRKU ออกจากการ์ดที่อยู่ในตัวอ่านการ์ดได้ และยังสามารถปิดการทำงานของสคริปต์บนการ์ด SD ได้อีกด้วย

ปิดกล้อง จากนั้นลบโฟลเดอร์ `SCRIPT` และ `GRKU` ออกจากการ์ด

การตั้งค่าสคริปต์บนการ์ด SD จะยังคงเปิดอยู่ หากต้องการปิดการทำงาน:

1. เข้าไปที่ https://grku.app แล้วดาวน์โหลดไฟล์สำหรับปิดสคริปต์บนการ์ด SD ที่ตรงกับรุ่นกล้องของคุณ
2. คัดลอกเนื้อหาทั้งหมดใน `SD_ROOT` ไปไว้ที่ไดเรกทอรีราก (root) ของการ์ด SD
3. ใส่การ์ดเข้าไปในกล้อง กดปุ่ม MENU ค้างไว้ขณะเปิดกล้อง รอจนกระทั่งกล้องปิดตัวเองลงโดยอัตโนมัติ
4. ลบไฟล์ `00078560.636` และ `DEVELOP.MOD` ออกจากไดเรกทอรีราก (root) ของการ์ด

หากกล้องค้างระหว่างการเปิดเครื่อง ให้อ่าน[คู่มือการกู้คืนระบบ](https://github.com/botnick/GRKU/blob/main/resources/RECOVERY.md)

GRKU ไม่มีส่วนเกี่ยวข้องใดๆ กับ Ricoh ซอร์สโค้ดและสัญญาอนุญาต: https://github.com/botnick/GRKU
