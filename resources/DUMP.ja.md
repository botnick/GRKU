# ファームウェア書き出しツール

ファームウェア書き出しツールは、カメラが実行中のファームウェアイメージをメモリーから SD カードにコピーします。開発者はこのイメージを使って、GRKU がまだ知らないファームウェアのバージョンに対応します。

このツールが必要になるのは、GRKU がカメラのファームウェアのバージョンに対応していない場合、または開発者が issue で書き出しを依頼した場合のみです。お使いのカメラで GRKU がすでに動作している場合は、必要ありません。

このツールはメモリーを読み取るだけです。カメラ、ファームウェア、カメラの設定は変更しません。書き出したファイルにはリコーのファームウェアだけが含まれます。写真や個人データは含まれません。

対象は RICOH GR III、GR IIIx、GR IV、GR IV Monochrome と、それぞれの HDF モデルです。どのカメラでも同じ ZIP を使います。

## 始める前に

- SD スクリプトがオンになっている必要があります。GRKU をインストールすると、オンになります。GRKU をインストールしたことがない場合は、まずお使いのカメラのインストールガイド（[GR III and GR IIIx](https://grku.app/guides/gr3/en.pdf)、[GR IV](https://grku.app/guides/gr4/en.pdf)）の手順 1 から 3 に従って GRKU を一度インストールしてください。
- このツールがカードにある間、GRKU は読み込まれません。
- 充電済みのバッテリーを使います。
- カメラのメニューからカメラのファームウェアバージョンを確認して控えておきます。報告時に必要になります。

## ツールの入手

[GRKU-dump.zip](https://github.com/botnick/GRKU/releases/latest/download/GRKU-dump.zip) をダウンロードします。[最新リリース](https://github.com/botnick/GRKU/releases/latest)の `GRKU-<バージョン>-dump.zip` と同じファイルです。

ZIP には `SD_ROOT/SCRIPT/STARTUP.TTL`、`SD_ROOT/SCRIPT/GRDUMP/DUMP.SH`、`SD_ROOT/SCRIPT/GRDUMP/DUMP.BIN`、`README.txt` が含まれています。

## ファームウェアを書き出す

1. カメラの電源を切ります。カードを取り出してコンピューターに入れます。
2. カードに `SCRIPT` フォルダーがある場合は、バックアップとしてコンピューターにコピーします。ない場合は、この手順をスキップします。
3. ツールを解凍します。`SD_ROOT` の中にある `SCRIPT` フォルダーをカードのルートにコピーします。コンピューターで確認が表示されたら、`SCRIPT/STARTUP.TTL` を置き換えます。
4. カードを安全に取り出します。カメラに入れます。通常どおり電源を入れます。MENU ボタンは押さないでください。
5. 電源を入れたまま 2 分待ちます。その後、電源を切ります。
6. カードをコンピューターに入れ、カードの `SCRIPT/GRDUMP` を開きます。

フォルダーに `DUMP.OK` があれば、書き出しは完了です。フォルダーには約 20 MB の `RTOS.BIN` と `INFO.TXT` もあります。

フォルダーに `DUMP.ERR` があれば、書き出しは失敗しています。`DUMP.ERR` にはエラーコードが記録されています。この場合もフォルダーを送ってください。

どちらのファイルもない場合、カメラはツールを実行していません。SD スクリプトがオンになっていることを確認します。その後、手順 4 から 6 をもう一度行います。

## ファイルを送る

1. `SCRIPT/GRDUMP` フォルダーを ZIP に圧縮します。
2. ZIP を [GitHub issue](https://github.com/botnick/GRKU/issues/new) に添付します。カメラの機種とファームウェアのバージョンを書きます。

開発者が issue で書き出しを依頼した場合は、その issue に ZIP を添付します。ZIP は約 20 MB です。GitHub は最大 25 MB のファイルを受け付けます。

## カードを元に戻す

1. カードから `SCRIPT` フォルダーを削除します。
2. 手順 2 でバックアップを作成した場合は、バックアップした `SCRIPT` フォルダーをカードにコピーします。

バックアップを戻すと、次に電源を入れたときに GRKU が再び読み込まれます。バックアップがない場合、カードは以前の状態に戻ります。お使いのファームウェアに対応した時点で、https://grku.app から GRKU をインストールしてください。
